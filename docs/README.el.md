# Fogbound — Οδηγός (Ελληνικά)

[← English README](../README.md)

Παιχνίδι λαβυρίνθου σε JavaScript + χειροποίητο απτικό χειριστήριο ESP32.
Το demo τρέχει **και χωρίς hardware**: όλο το κύκλωμα προσομοιώνεται στη σελίδα.

## Γρήγορη εκκίνηση

1. Άνοιξε το `index.html` σε **Chrome ή Edge** (desktop). Για το Web Serial είναι καλύτερα να το σερβίρεις τοπικά:
   ```bash
   npx serve .
   ```
   και μετά άνοιξε τη διεύθυνση `http://localhost:3000`.
2. Το παιχνίδι είναι σε πρώτο πρόσωπο, με ομίχλη. Joystick πάνω/κάτω (`W`/`S`) = βήμα μπροστά/πίσω, αριστερά/δεξιά (`A`/`D`) = στροφή 90°.
3. `Space` = SW (επανάληψη υπόδειξης), `M` = BTN1 (Visual/Haptic), `R` = BTN2 (restart), `F` = πλήρης οθόνη.
   - **Visual**: αραιή ομίχλη + χάρτης στη γωνία.
   - **Haptic**: πυκνή ομίχλη, χωρίς χάρτη: πλοηγείσαι με τις δονήσεις.
4. Με ακουστικά, ο «ήχος δόνησης» βγαίνει αριστερά/δεξιά όπως τα πραγματικά μοτέρ.

## Δυσκολία

| Επίπεδο | Ρούνοι για να ανοίξει η πύλη | Σκιά |
|---|---|---|
| Εύκολο | 0 | όχι |
| Κανονικό | 1 | αργή, σε κυνηγάει όταν απέχει ≤ 6 βήματα |
| Δύσκολο | 3 | γρήγορη, σε κυνηγάει όταν απέχει ≤ 10 βήματα |

Η πύλη είναι κόκκινη και σφραγισμένη μέχρι να μαζέψεις όλους τους ρούνους. Οι υποδείξεις οδηγούν πρώτα στον πιο κοντινό ρούνο και μετά στην πύλη. Αν σε πιάσει η Σκιά, γυρνάς στην αρχή, αλλά κρατάς τους ρούνους που έχεις μαζέψει.
Όσο η Σκιά είναι κοντά, το χειριστήριο «γουργουρίζει» (μοτίβο `E`), όλο και πιο συχνά όσο πλησιάζει. Αυτό είναι ένα **δεύτερο απτικό κανάλι** (απειλή), παράλληλο με την πλοήγηση. Στο Haptic mode ο κίνδυνος γίνεται αισθητός μόνο μέσω της δόνησης, χωρίς οπτική ένδειξη.

Τα props (μαγκάλια, βαρέλια, κιβώτια, αλυσίδες) είναι διακοσμητικά και δεν εμποδίζουν την κίνηση. Τα μαγκάλια φωτίζουν τον χώρο γύρω τους.

## Τι περιέχει

| Αρχείο | Ρόλος |
|---|---|
| `js/maze.js` | Δημιουργία λαβυρίνθου με seed (ίδιος seed = ίδιος λαβύρινθος) |
| `js/navigation.js` | BFS: απόσταση κάθε κελιού από την έξοδο, επόμενο σωστό βήμα |
| `js/haptics.js` | Απτικό λεξιλόγιο (μοτίβα) + player + ηχητική προσομοίωση |
| `js/game.js` | Κανόνες κίνησης πρώτου προσώπου, μετρητές, κάμερα |
| `js/raycaster.js` | Raycaster 320×240: υφές, ομίχλη, πύλη εξόδου, minimap |
| `js/circuit.js` | Το εικονικό σχηματικό (SVG), live τιμές ακροδεκτών |
| `js/scope.js` | Παλμογράφος για GPIO18/19 και ADC |
| `js/serial.js` | Σύνδεση με το πραγματικό ESP32 μέσω Web Serial |
| `js/main.js` | Σύνδεση όλων: είσοδοι → παιχνίδι → δονήσεις → hardware |
| `esp32/firmware/firmware.ino` | Κώδικας για το ESP32 (Arduino IDE) |

## Απτικό λεξιλόγιο

| Κωδικός | Σημασία | Μοτίβο |
|---|---|---|
| `L` | στρίψε αριστερά | αριστερό μοτέρ, 170 ms |
| `R` | στρίψε δεξιά | δεξί μοτέρ, 170 ms |
| `U` | προχώρα μπροστά | και τα δύο, 90 ms |
| `D` | ο δρόμος είναι πίσω σου | και τα δύο, 2 × 80 ms |

Οι υποδείξεις είναι **σχετικές με το πού κοιτάς**: ο BFS δίνει το επόμενο βήμα σε απόλυτη κατεύθυνση (Β/Α/Ν/Δ) και το παιχνίδι το μετατρέπει σε «αριστερά / δεξιά / μπροστά / πίσω» ως προς τον παίκτη.
| `W` | τοίχος | και τα δύο, 450 ms |
| `G` | έξοδος | αριστερά-δεξιά ×2 + μακρύς |
| `K` | μάζεψες ρούνο | αριστερά → δεξιά → και τα δύο |
| `E` | κίνδυνος: η Σκιά είναι κοντά | 4 πολύ γρήγοροι παλμοί, που επαναλαμβάνονται πιο συχνά όσο πλησιάζει |
| `X` | σε έπιασε η Σκιά | 2 μεσαίοι + 1 πολύ μακρύς |

## Συνδεσμολογία

| Εξάρτημα | Ακροδέκτης | ESP32 |
|---|---|---|
| Joystick KY-023 | GND / +5V / VRx / VRy / SW | GND / **3V3** / GPIO34 / GPIO35 / GPIO32 |
| BTN1 (mode) | ένα άκρο / άλλο άκρο | GPIO25 / GND |
| BTN2 (restart) | ένα άκρο / άλλο άκρο | GPIO26 / GND |
| Μοτέρ αριστερό | GPIO18 → 1 kΩ → βάση Q1 · εκπομπός Q1 → GND · συλλέκτης Q1 → (−) μοτέρ · (+) μοτέρ → 3V3 | |
| Μοτέρ δεξί | ίδιο, με GPIO19 και Q2 | |
| Δίοδοι 1N4001 | παράλληλα σε κάθε μοτέρ, η γραμμή (κάθοδος) προς το 3V3 | |
| LED1 (link) | GPIO16 → 220 Ω → άνοδος LED · κάθοδος → GND | |
| LED2 (haptic) | GPIO17 → 220 Ω → άνοδος LED · κάθοδος → GND | |
| OLED SSD1306 | GND / VCC / SCL / SDA | GND / 3V3 / GPIO22 / GPIO21 |

⚠️ Έλεγξε στο datasheet του δικού σου transistor ποιο ποδαράκι είναι E-B-C, γιατί αλλάζει ανά κατασκευαστή.
⚠️ Το joystick πάει στο 3V3, όχι στο 5V: τα GPIO του ESP32 δεν αντέχουν 5 V.

## Firmware

1. Arduino IDE → Boards Manager → εγκατάσταση **esp32 by Espressif**.
2. Library Manager → **Adafruit SSD1306** και **Adafruit GFX**.
3. Board: **ESP32 Dev Module**, άνοιξε `esp32/firmware/firmware.ino`, Upload.
4. **Κλείσε το Serial Monitor** και πάτα «Σύνδεση ESP32» στη σελίδα.

Χωρίς υπολογιστή, το ESP32 μπαίνει σε test mode: σπρώξε το joystick αριστερά/δεξιά και πρέπει να δονηθεί το αντίστοιχο μοτέρ.
Αν οι κατευθύνσεις του πραγματικού joystick βγαίνουν ανάποδα, χρησιμοποίησε τα κουτάκια «Βαθμονόμηση» που εμφανίζονται μετά τη σύνδεση.

## Πρωτόκολλο σειριακής (115200 baud)

```
PC  → ESP32   H:L                 παίξε μοτίβο
PC  → ESP32   S:H,12,34,L,0       mode, κινήσεις, δευτ., τελευταίο μοτίβο, νίκη
ESP32 → PC    J:2048,1950,0,0,0   x, y, sw, btn1, btn2  (~30 Hz)
```

## Πείραμα χρηστών

Κάθε λαβύρινθος που λύνεται καταγράφεται στον πίνακα «Πείραμα χρηστών» (χρόνος, κινήσεις, λάθη, τοίχοι, υποδείξεις, αποδοτικότητα).
Χρησιμοποίησε τον ίδιο seed για Visual και Haptic, άλλαξε τη σειρά των modes ανά συμμετέχοντα και κατέβασε τα αποτελέσματα με «Εξαγωγή CSV».
